| 「다루는 요구」 절을 선택 절로 바꿀지 | 써보고 정한다(ADR-0001) |
| 파일 번호 규칙(`0001-`)을 템플릿에 적을지 | 써보고 정한다(ADR-0001) |
| plan 템플릿 항목에 이슈 번호 자리를 둘지 | 써보고 정한다(ADR-0001). 지금은 스킬이 「번호가 없으면 건너뛴다」로 적는다 |

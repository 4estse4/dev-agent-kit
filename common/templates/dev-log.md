# Dev Log

AI 협업·결정 기록. PR 단위로 덧붙인다.

**왜 남기나**: 나중에 "AI 를 어떻게 썼는가"를 쓸 때, 결론만 있으면 재구성이 안 된다.
**누가 제안하고 누가 짚었고 왜 채택·폐기했는지**가 1차 재료다.

**형식** — 한 항목은 짧게. 화자를 `[AI]` `[사람]` 으로 표시한다. 둘이 함께 정한 것은 제안한 쪽과
승인한 쪽을 각각 적는다(「`[AI]` 제안 → 사람이 승인」).

## YYYY-MM-DD — <주제> (PR #N)

- **작업**: <무엇을 만들었나. 한두 줄.>

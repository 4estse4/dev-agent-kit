# SPEC — <프로젝트명>

> 이 문서는 **무엇을 / 왜**(요구·제약·범위)를 정의한다. 구현 방식은 plan 에,
> 결정 근거는 `docs/adr/` 에 둔다. 여기 있는 모든 요구는 ID 를 갖고 `docs/traceability.md`
> 에 한 행씩 대응해야 한다. ID 가 있는 요구에 행이 있는지는 `trace.sh` 가 기계로 확인한다.

## 요구 ID 규칙

`R-<영역>-<번호>` 형식. 영역은 프로젝트가 정한다(`GEN`·`OBS`·`SEC`·`DATA` 등). 영역은 영어 대문자로 시작하고 영어
대문자와 숫자만 쓴다. `trace.sh` 는 이 형식이 아닌 ID 를 요구로 읽지 않는다.

**ID 는 한 번 부여하면 바꾸지 않는다.** 요구가 사라지면 삭제하지 말고
상태를 `범위밖` 으로 바꾼다. 그래야 "언젠가 있었는데 아무도 모르게 없어진" 요구가 안 생긴다.

# 추적 매트릭스

`docs/SPEC.md` 의 요구마다 구현과 테스트가 어디 있는지 적는다.
**`bash .kit/gate/trace.sh` 가 이 표를 기계로 검사한다** — CI 에서도 실행된다. 검사가 확인하는 것은 SPEC 의 요구 ID 마다
행이 있는지, SPEC 에 없는 ID 의 행이 없는지, 상태 칸이 넷 가운데 하나인지, `구현됨` · `부분` 행의 구현 · 테스트 칸에 적힌
경로가 실재하는지다. 같은 ID 의 행이 둘이거나 테스트 칸이 `—` 여도 검사는 통과한다. 그 테스트가 요구를 다루는지와
통과하는지는 확인하지 않는다.

## 규칙

- SPEC 의 모든 요구 ID 는 여기 **정확히 한 행**을 갖는다.
- **상태 칸을 비워두지 않는다.** 빈 칸은 검사 실패다.
- 상태는 넷 중 하나: `구현됨` · `부분` · `미구현` · `범위밖`
- `구현됨` / `부분` 이면 구현 칸과 테스트 칸에 실재하는 파일 경로를 적는다(검사가 존재를 확인한다).
- **`미구현` 은 실패가 아니라 정상적인 상태다.** 숨기는 것이 실패다.

| 요구     | 제목   | 구현              | 테스트                 | 상태   | 비고                 |
| -------- | ------ | ----------------- | ---------------------- | ------ | -------------------- |
| R-XXX-01 | <제목> | `path/to/file.go` | `path/to/file_test.go` | 구현됨 |                      |
| R-XXX-02 | <제목> | —                 | —                      | 미구현 | <왜 안 했는지 한 줄> |

# .ai-kit/baseline/ 은 무엇인가

**킷이 설치할 당시의 원본 사본이다.** 같은 파일이 두 벌 있는 것처럼 보이지만 의도된 것이다.

```
AGENTS.md                     ← 이 프로젝트가 고쳐 쓰는 파일
.ai-kit/baseline/AGENTS.md    ← 킷이 원래 준 것 (건드리지 않는다)
```

## 왜 필요한가

`install.sh --update` 는 **3-way 병합**을 한다. "프로젝트가 고친 것"과 "킷이 바꾼 것"을
둘 다 살리려면 **둘의 공통 조상**이 있어야 하고, 그것이 이 디렉터리다.

없으면 갱신이 "덮어쓰기 아니면 포기" 둘 중 하나가 된다 — 프로젝트 수정을 날리거나,
킷 개선을 영영 못 받거나.

## 커밋해야 하나

**그렇다.** 커밋하지 않으면 이 레포를 새로 clone 한 사람이 갱신할 때 기준점을 잃는다.

## 지우면

`--update` 가 `.ai-kit/VERSION` 의 `kit_rev` 로 킷 히스토리에서 원본을 복원하는 경로로
내려간다. 그 커밋이 킷에 남아 있어야만 동작하므로(히스토리를 재작성하면 사라진다)
확실한 쪽은 이 디렉터리를 두는 것이다.

## 손으로 고치지 마라

여기 파일을 고치면 병합 기준이 거짓이 되어, 다음 갱신이 엉뚱한 충돌을 내거나
있어야 할 충돌을 놓친다. 갱신은 `install.sh --update` 가 알아서 갱신한다.
